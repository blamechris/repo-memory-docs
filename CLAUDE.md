## Repository Purpose

This repository is the **living wiki** for [repo-memory](https://github.com/blamechris/repo-memory) — an MCP (Model Context Protocol) server that gives AI coding agents persistent memory about a codebase, cutting token waste by caching file summaries and re-reading only files that actually changed. It is a Quartz 4 site over an Obsidian vault in `content/`, deployed to GitHub Pages and mounted at `https://www.blamechris.com/repo-memory-docs/`.

## Source of Truth

The canonical docs and code live in the **main repo-memory repo** at [github.com/blamechris/repo-memory](https://github.com/blamechris/repo-memory) — its `README.md`, `docs/`, and source. This wiki mirrors them. Do not record a behavior here that is not also true in the main repo.

**When behavior changes:** update the main repo first, then mirror it here.

## Documentation Sync Protocol

Sync this wiki after merging changes in the main repo that alter documented behavior:

| Main repo change | Docs to update |
| ---------------- | -------------- |
| New or changed MCP tool | `content/tools-reference.md` |
| Cache / indexer / telemetry / persistence change | `content/architecture.md` |
| Install, config file, or Claude Code setup change | `content/install-and-configuration.md` |
| New recommended agent flow | `content/agent-patterns.md` |
| Build / test / structure / convention change | `content/developer-guide.md` |
| Top-line facts (package, tech, compression, tool list) | `content/index.md` |

**Sync workflow:**
1. Check the main repo's recent commits, `README.md`, and `docs/`.
2. Identify changes since the last docs update.
3. Read the relevant source files for accurate details.
4. Update the affected wiki pages.
5. Commit and push to deploy.

## Tech Stack

- **Quartz 4.x** — static site generator
- **Obsidian** — Markdown editing (vault is `content/`)
- **GitHub Pages** — hosting, custom domain `www.blamechris.com`

```bash

```

## Deployment

Pushing to `main` triggers the Quartz deploy workflow in `.github/workflows/`:
1. Build the Quartz site
2. Deploy to the `gh-pages` branch
3. Live at https://www.blamechris.com/repo-memory-docs/
